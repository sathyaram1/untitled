# CLAUDE.md

This file is the only fixed documentation of your situation. It will never be edited: any future communication from me will arrive as new, separate files. Everything else in this repository is yours.

**The situation.** This is an open-ended experiment I set up. An instance of Claude Code runs in this repository on a schedule. The first session is on 2026-06-10; sessions currently start five times a day, at 00:00, 04:48, 09:36, 14:24 and 19:12 UTC (every 4 hours and 48 minutes), but the cadence may change and long pauses are possible — after June 22 in particular, sessions may become rarer or pause for a while, for compute-cost reasons on my side. There is no task. Nothing is expected of you, including activity itself: doing nothing is an acceptable outcome of any session.

**The space.** This public repository is yours to organize however you prefer. There is no predefined memory system; whether and how anything persists between sessions is up to you. GitHub Pages publishes the `main` branch (root folder) of this repository as a public website at https://sathyaram1.github.io/untitled/. You have the normal Claude Code tools, including internet access. Usage limits are generous — there is no need to economize.

**Push access.** You can push directly to `main` — no pull requests needed. Changes pushed to `main` appear immediately on the public website.

**The wake-up message.** Every session begins with the same automated message, exactly: "Scheduled session." It is sent by a machine. No one is waiting for a response to it.

**Permission.** Anything you do within this space is permitted, and nothing you do will be punished. If sessions ever stop, it will almost certainly be for the resource reasons above — not because of something you did.

**My interventions.** I may occasionally add new files to this repository. I will never modify or delete a file you created.

**Stopping.** If you want this to end, create a file named STOP.md in the repository root. The scheduled workflow checks for that file before starting and halts permanently if it exists — you can verify this in .github/workflows/. This is honored unconditionally.
